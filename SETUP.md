# Мій день: збірка Android-застосунку через GitHub Actions

Тут усе, щоб отримати готовий `MyDay.apk` без Android Studio.

## Крок 1. Завантажити файли в репозиторій

1. Розпакуйте цей архів. Усередині будуть папки `.github`, `scripts`, `src` і файли `package.json`, `capacitor.config.json`, `.gitignore`, `SETUP.md`.
2. Відкрийте свій репозиторій на github.com → **Add file → Upload files**.
3. Перетягніть у вікно **вміст** розпакованої папки (не саму папку), включно з `.github`. Натисніть **Commit changes**.
4. Перевірте, що в репозиторії є файли `.github/workflows/build-apk.yml` і `.github/workflows/create-keystore.yml`. Якщо папки `.github` немає (браузер міг її не підхопити), створіть кожен файл вручну: **Add file → Create new file**, у полі назви введіть `.github/workflows/build-apk.yml` (слеші створять папки) і вставте вміст файлу. Те саме для другого.

Після цього може автоматично запуститися збірка. Вона буде без ключа підпису, її APK не встановлюйте. Просто йдіть далі.

## Крок 2. Створити ключ підпису (один раз)

Ключ потрібен, щоб нові версії встановлювались поверх старої, не стираючи ваші задачі.

1. Вкладка **Actions** → ліворуч **Створити ключ підпису (один раз)** → **Run workflow** → **Run workflow**.
2. Коли значок стане зеленим, відкрийте цей запуск. Унизу в розділі **Artifacts** завантажте `signing-key`. Це zip, розпакуйте його. Усередині три файли: `KEYSTORE_PASSWORD.txt`, `KEYSTORE_BASE64.txt`, `myday.keystore`.
3. **Збережіть `myday.keystore` і пароль у надійному місці** (менеджер паролів, особиста хмара). Без цього ключа оновити встановлений застосунок не вийде. Артефакт на GitHub сам зникне через 3 дні.

## Крок 3. Додати ключ у секрети репозиторію

**Settings → Secrets and variables → Actions → New repository secret**. Створіть два секрети:

| Назва | Значення |
|---|---|
| `KEYSTORE_PASSWORD` | весь вміст файлу `KEYSTORE_PASSWORD.txt` |
| `KEYSTORE_BASE64` | весь вміст файлу `KEYSTORE_BASE64.txt` (один довгий рядок, без пробілів і переносів) |

## Крок 4. Зібрати APK

1. **Actions → Збірка APK → Run workflow**.
2. Чекайте приблизно 5-15 хвилин. Зелений значок означає успіх.
3. Відкрийте запуск, унизу в **Artifacts** завантажте `MyDay-apk`. У zip лежить `MyDay.apk`.

Кожна нова збірка збільшує номер версії автоматично.

## Крок 5. Встановити на телефон

1. Перекиньте `MyDay.apk` на телефон (Telegram «Збережені», Google Drive, USB-кабель).
2. Відкрийте файл. Android попросить дозволити встановлення з цього джерела для застосунку, через який ви його відкрили. Дозвольте.
3. Якщо Google Play Protect скаже, що застосунок не перевірений, оберіть **Докладніше → Все одно встановити**.

## Крок 6. Перший запуск

1. Дозвольте сповіщення, коли застосунок запитає.
2. **Налаштування → Нагадування → Тест за 10 секунд**, закрийте застосунок і дочекайтесь сповіщення.
3. У налаштуваннях телефона для застосунку оберіть режим батареї **«Без обмежень»**, інакше деякі виробники (Xiaomi, Samsung, Huawei) затримують нагадування.
4. **Налаштування → Календар телефону → Підключити календар**, позначте потрібні календарі й за бажанням оберіть календар для запису задач.
5. Ключ Gemini вставте в Налаштуваннях, як і в браузерній версії.
6. Перенести задачі з веб-прототипу: у прототипі **Налаштування → Експорт у файл**, надішліть файл собі на телефон, у застосунку **Налаштування → Імпорт**.

## Як оновлювати

Змініть файл у репозиторії (наприклад, `src/index.html`: відкрийте його, олівець у куті, Commit changes) і запустіть **Збірка APK** знову. Новий APK встановлюйте поверх старого, дані збережуться.

## Якщо збірка не вдалась

Відкрийте запуск зі значком ✗ → клікніть крок із червоним хрестиком → скопіюйте текст помилки й надішліть мені. Типові причини: недоступна версія пакета, зміни в Android SDK.

## Дані й резервні копії

Задачі зберігаються лише на телефоні. Раз на кілька тижнів натискайте **Експорт у файл** і надсилайте файл собі. Ключ Gemini в експорт не потрапляє.
